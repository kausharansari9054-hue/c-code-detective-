## 📖 Description
C Code Detective – Bug Hunter is an interactive coding quiz game designed to improve C programming and debugging skills. Players identify errors in code snippets and select the correct answers.

The game provides three difficulty levels: Easy, Medium, and Hard. It is beginner-friendly and makes learning C programming fun and interactive.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- C Programming Concepts

## 🚀 How to Play
1. Open the game link.
2. Enter your name.
3. Select a difficulty level.
4. Answer the debugging questions.
5. Check your score and play again!

## 🎯 Project Objective
To help beginners understand C programming concepts and improve their debugging skills through an interactive quiz game.
